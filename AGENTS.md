# Agent instructions

This is an AgentPlugins plugin. Keep changes minimal and focused on the plugin manifest, build outputs, and cross-platform compatibility.

- Prefer editing `agentplugins.config.ts` over generated harness files.
- Run `pnpm run validate` and `pnpm run build` before committing.
- Keep Tier-1 harness parity: Claude Code, Codex, OpenCode, Pi Mono.
- Atomic conventional commits.
